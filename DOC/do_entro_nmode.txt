  SCRIPT's NAME:  do_entro_nmode.sh

  GOAL: To carry out entropy calculations using the RRHO approximation.
        This script drives both the preliminary energy minimizations and
        the normal mode calculations setting the choices and parameters
        summarized in $APTAMD/DOC/entropy_nmode.txt 


  USAGE : do_entro_nmode.sh  "MOL1 MOL2 ..."   MD_TYPE  

  where MOL1, MOL2 (enclosed in quotation marks) are the project alias of
  the MD trajectories of interest. MD_TYPE can be either "MD" or "GAMD". 
 
          do_entro_nmode.sh  input.src       
 
  If the input filename has src extension then do_entro_nmode.sh sources it 
  The lines in the src file should contain variable declarations for 
  the various options indicated below.

  This script must be called from the main directory where the MD/GAMD 
  directories are located. See $APTAMD/DOC/directory_tree.txt for details.

  OPTIONS: (selected by environment variables) 

    MOL='alias'        # Project alias. Several aliases can be grouped
                       # into a single variable MD_TRAJ='MOL1 MOl2 ...'
    MD_TYPE='MD'       # Either MD or GAMD

    NPROCS=6           # Number of cores to be used. Def all available.

    CNTION_LIST="Na+ MG"  # List of counterion residue names to be 
                          # included in the MMPBSA calcs. Default is Na+

    NCNTION_LIMIT=0    # Number of counterions to be included in the calcs. 
                       The counterion are selected on the basis of their
                       proximity to the solute atoms. Default = 0.
                       If your system has various fragments (e.g.,
                       receptor and fragments), you have to specify 
                       a given number of counterions per fragment. For example,
                       NCNTION_LIMIT=' 6:0 0:1 ' means that there are 2 
                       fragments and 6 and 0 ions are of the first and second
                       type (e.g., CNTION_LIST='Na+ MG') are assigned to the
                       the first fragment while 0 and 1 ions of the first
                       and second type are assigned to the second fragment. 

                       For compatibility reasons, NSODIUM_LIMIT=" 4 1 " is
                       translated as CNTION_LIST="Na+" and NCNTION_LIMIT="4:1"
                       Do not use, however, the NSODIUM_LIMIT variable.

    CNTION_FRAG='NO'  # Unless CNTION_FRAG='YES', the counterions are
                        assigned to the molecular fragments. SODIUM_FRAG
                        is interpreted as CNTION_FRAG.            

    SNAPSHOTS_DIR='SNAPSHOTS' # Directory containing the PDB files 
                                 and located in 6.ANALYSIS

    ENTRO_DIR='ENTRO_NMODE'  # Output directory. 

    TEMPERATURE="300.0"      # Temperature value for RRHO calculations
                             # Defaault is 300.0 K

    NUMPDB_INCR=0   # If a MD trajectory is extended and the number of PDB
                         files is augmented then previous run of do_entro_nmode
                         on the shorter trajectory can be augmented by indicating
                         the additional number of PDB files to be processed. For 
                         example, if NUMPDB_INCR=500 then only the newest 500 PDB 
                         files are to be processed. 

    SIEVE=1    #  ENTROPY calcs are done with a sieve=#SIEVE of PDB frames

    PREFIX_MDCRD='md_'   # Although a list of PDB files generated by do_snapshots
                         # is processed, PREFIX_MDCRD and SUFFIX_MDCRD specifiy
                         # the source and topology data used to build the PDBs.
    SUFFIX_MDCRD='_solutewat.mdcrd'
